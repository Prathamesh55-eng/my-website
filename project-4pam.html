About the Project

This project explores noise-aided demodulation of multilevel Pulse Amplitude Modulation signals using a one-bit comparator. The focus is on 4-PAM signal detection using the statistical information contained in multiple comparator outputs.

Problem Statement

A conventional one-bit comparator produces only two output levels. Therefore, a single comparator output cannot directly represent all four amplitude levels of a 4-PAM signal.

The project investigates how noise can be used to make the comparator output stochastic and how the resulting samples can be processed to recover information about the transmitted multilevel symbol.

4-PAM Signal

The four possible transmitted symbols used in the system are:

-3A
-A
+A
+3A

Noise-Aided Detection

Although the comparator itself produces only two levels, the noise causes its output to switch probabilistically. The statistical behavior of multiple comparator samples contains information about the transmitted amplitude.

The samples are combined to obtain a decision statistic, which is then used to estimate the most likely transmitted symbol.

Maximum-Likelihood Detection

The receiver estimates the transmitted symbol by selecting the symbol having the highest likelihood for the observed decision statistic.

Estimated Symbol =

arg max P(y | d)
