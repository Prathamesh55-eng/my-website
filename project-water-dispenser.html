Automatic Water Dispenser

A contactless IoT-enabled system for automatic and hygienic water dispensing

Prototype of the automatic water dispenser using Arduino, ultrasonic sensor, relay module and water pump.

About the Project

The Automatic Water Dispenser is designed to supply water automatically when a user places a hand or glass near the dispenser. The system uses an ultrasonic sensor to detect the object and a microcontroller-controlled relay to operate the water pump.

The contactless operation helps reduce water wastage, improves hygiene and provides a convenient method of controlled water delivery.

Problem Statement

Manual water taps can cause unnecessary water wastage when users forget to turn them off properly. Physical contact with taps can also affect hygiene. The project addresses this by providing an automatic, contactless system that controls water flow based on object detection.

How It Works

01 Ultrasonic Sensor Detects Object
02 Distance is Measured
03 Arduino Processes the Input
04 Relay is Activated
05 Water Pump Turns ON
06 Pump Stops When Object is Removed

System Components

Arduino Ultrasonic Sensor Relay Module Water Pump Power Supply

Results

  • Object detection was successfully achieved within 10 cm.
  • The Arduino automatically activates the relay when an object is detected.
  • The water pump starts automatically when the relay is activated.
  • Water dispensing stops when the hand or glass is removed.
  • The system operates without physical contact.
  • The prototype showed stable and repeatable operation under normal indoor conditions.

Key Advantages

The system reduces unnecessary water usage and eliminates direct contact with the tap. The relay also provides power isolation between the Arduino and the higher-current pump load.

Future Scope

The system can be expanded with additional features such as an LCD display, solenoid valve and IoT-based monitoring or control.
