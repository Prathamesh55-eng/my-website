MY PROJECT

Foot Drop Detection using EMG and FPGA

A hardware-based system designed to detect foot drop using EMG signals, digital signal processing and FPGA.

About the Project

This project focuses on detecting abnormal muscle activity associated with foot drop. EMG signals are acquired from the muscles and processed digitally before being implemented on an FPGA.

Technologies Used

EMG Sensor | FIR Filter | Verilog | FPGA | MATLAB

My Contribution

Designed and simulated Verilog modules, developed testbenches and worked on digital signal processing for the FPGA implementation.
